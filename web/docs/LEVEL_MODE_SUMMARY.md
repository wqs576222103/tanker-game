## 三、技术架构

### 数据流
```
LevelSelect → LevelGame → base.js (游戏引擎)
     ↓              ↓              ↓
 关卡配置      游戏状态      胜利检测
     ↓              ↓              ↓
 localStorage   事件总线    进度保存
```

### 关键设计点

1. **最小侵入式修改**: 仅修改 base.js 的 4 个函数，新增全局变量不影响原有逻辑
2. **事件驱动**: 使用 CustomEvent 传递关卡状态变化
3. **配置优先**: 关卡数据集中在 levels.js，易于扩展
4. **向后兼容**: 未激活关卡模式时，所有原有功能不受影响

## 六、开发第二关的指导

参见详细文档：`web/docs/LEVEL_MODE_DEVELOPMENT.md`

**快速开始：**
1. 打开 `web/src/views/TankGame/script/levels.js`
2. 在 LEVELS 数组末尾添加新关卡对象
3. 使用 `createMap()` 函数或程序化生成地图
4. 配置 objective、playerSpawn、enemySpawns 等参数
5. 访问 `/level/2` 测试

## 七、已知限制

1. **夺旗机制**: 当前仅实现基础检测，视觉反馈和AI行为待完善
2. **地图尺寸**: 固定为45×30网格，暂不支持动态尺寸
3. **多玩家**: 关卡模式仅支持单人，多人协作待后续开发

# 自定义地图脚本编写指南

### 生成脚本必须为 JavaScript

本指南帮助你编写自定义地图脚本，导入后游戏将使用你设计的地图。

---

## 快速开始

脚本必须导出一个地图配置对象，支持两种方式：

**方式一：ES Module（推荐）**
```js
export default {
  name: "我的迷宫",
  map: [
    // 30 行，每行 45 个数字
  ],
};
```

**方式二：全局变量**
```js
window.__MAP__ = {
  name: "我的迷宫",
  map: [
    // 30 行，每行 45 个数字
  ],
};
```

---

## 一、完整配置项

```js
export default {
  name: "我的地图",           // string，可选，地图名称

  map: [                     // number[][]，必填，30行 x 45列
    [3,3,3,3,...],           // 第0行（上边界）
    [3,0,0,0,...],           // 第1行
    // ... 共30行
    [3,3,3,3,...],           // 第29行（下边界）
  ],

  gates: [],                 // 可选，传送门配对列表
  crackHp: {},               // 可选，碎石墙HP {"c,r": hp}
  playerSpawn: { c: 22, r: 20 },  // 可选，玩家出生格子
  enemySpawns: [             // 可选，敌人出生点
    { c: 1, r: 1 },
    { c: 43, r: 1 },
  ],
  items: [],                 // 可选，预置道具
  fallingStones: [],         // 可选，天空落石位置 [{ c, r }]
  initialEnemies: 2,         // 可选，初始敌人数量
};
```

---

## 二、地图格子类型常量

地图是一个 30行 x 45列 的二维数组，每个格子用一个数字表示类型：

| 常量名 | 值 | 含义 | 可通过 | 阻挡子弹 |
|--------|---|------|--------|----------|
| EMPTY | 0 | 空地 | 是 | 否 |
| WALL | 1 | 砖墙（不可破坏） | 否 | 是 |
| GATE | 2 | 传送门 | 是 | 否 |
| BORDER | 3 | 地图边界 | 否 | 是 |
| CRACK | 4 | 碎石墙（可破坏） | 否 | 是 |
| GRASS | 5 | 草丛（可隐藏坦克） | 是 | 是 |
| SPEED | 6 | 加速地形 | 是 | 否 |
| SPIKE | 7 | 陷阱（周期伤害） | 是 | 否 |
| DOOR | 9 | 可开关门 | 视状态 | 是 |
| SWITCH | 10 | 开关（控制门） | 是 | 否 |
| PORTAL | 11 | 传送门（胜利目标） | 是 | 否 |
| CRATE | 12 | 可推动箱子 | 否 | 是 |

> **注意**：地图最外圈（第0行、第29行、第0列、第44列）应设为 BORDER(3)。

---

## 三、地图尺寸

- 列数（COLS）：45
- 行数（ROWS）：30
- 格子大小（CELL）：20 像素
- 画布尺寸：900 x 600 像素

`map` 数组结构：`map[行号][列号]`，即 `map[r][c]`。

---

## 四、传送门配置（gates）

传送门需要成对配置，坦克走进一个传送门会被传送到配对的传送门。

```js
export default {
  name: "传送门地图",
  map: [ /* ... */ ],
  gates: [
    {
      pair: "a",  // 配对标识，相同 pair 的门互相传送
      cells: [
        // 本门占据的格子（可以是多个格子）
        { c: 1, r: 14 },
      ],
      partnerCells: [
        // 配对门占据的格子
        { c: 43, r: 14 },
      ],
    },
    {
      pair: "b",
      cells: [{ c: 22, r: 1 }],
      partnerCells: [{ c: 22, r: 28 }],
    },
  ],
};
```

---

## 五、碎石墙 HP（crackHp）

碎石墙（CRACK = 4）默认 HP 为 2-3，可通过 `crackHp` 自定义：

```js
crackHp: {
  "5,5": 5,    // 第5列第5行的碎石墙 HP 为 5
  "10,8": 1,   // 第10列第8行的碎石墙 HP 为 1
},
```

键格式为 `"列,行"`（`"c,r"`），值为正整数。

---

## 六、预置道具（items）

在地图上预先放置道具，开局即可拾取：

```js
items: [
  { c: 10, r: 10, type: "drone" },   // 第10列第10行放置无人机
  { c: 20, r: 15, type: "shield" },  // 第20列第15行放置护盾
  { c: 30, r: 20, type: "mine" },    // 第30列第20行放置地雷
],
```

可用道具类型：

| type | 名称 | 说明 |
|------|------|------|
| drone | 无人机 | 伴飞坦克自动射击 |
| spread | 散弹 | 扩散射击模式（18秒） |
| fire | 射速 | 提升射击速度（9秒） |
| speed | 移速 | 提升移动速度（9秒） |
| shield | 护盾 | 免伤护盾（9秒） |
| mine | 地雷 | 携带地雷（+3颗） |
| heal | 生命 | 恢复1点生命值 |
| bounce | 反弹 | 子弹可反弹一次 |

---

## 七、天空落石配置（fallingStones）

游戏过程中会自动从天空掉落落石（每5秒一块），可配置落石砸向的固定位置：

```js
fallingStones: [
  { c: 10, r: 5 },   // 石头砸向第10列第5行
  { c: 20, r: 10 },  // 石头砸向第20列第10行
  { c: 30, r: 15 },  // 石头砸向第30列第15行
],
```

- 坐标格式：`{ c: 列号, r: 行号 }`
- 石头会按配置顺序循环生成
- 如果坐标位置是墙壁/边界/碎石墙，该次落石会跳过
- **未配置时**：石头会随机砸向地图上的空地
- 落石有1.5秒预警提示（红色圈），之后砸下造成范围伤害

---

## 八、出生点配置

```js
playerSpawn: { c: 22, r: 20 },  // 玩家出生格子（默认值）

enemySpawns: [                   // 敌人出生点列表
  { c: 1, r: 1 },               // 左上角
  { c: 43, r: 1 },              // 右上角
],
```

---

## 九、完整示例

```js
export default {
  name: "经典迷宫",
  map: (() => {
    const EMPTY = 0, WALL = 1, BORDER = 3, CRACK = 4, GRASS = 5;
    const m = [];
    for (let r = 0; r < 30; r++) {
      const row = [];
      for (let c = 0; c < 45; c++) {
        if (r === 0 || r === 29 || c === 0 || c === 44) {
          row.push(BORDER);
        } else {
          row.push(EMPTY);
        }
      }
      m.push(row);
    }
    // 添加一些墙壁
    for (let c = 10; c < 20; c++) m[5][c] = WALL;
    for (let c = 25; c < 35; c++) m[10][c] = CRACK;
    for (let r = 15; r < 25; r++) m[r][15] = WALL;
    // 添加草丛
    for (let r = 12; r < 16; r++)
      for (let c = 20; c < 24; c++) m[r][c] = GRASS;
    return m;
  })(),

  playerSpawn: { c: 22, r: 20 },
  enemySpawns: [
    { c: 1, r: 1 },
    { c: 43, r: 1 },
  ],

  gates: [
    {
      pair: "h",
      cells: [{ c: 1, r: 14 }],
      partnerCells: [{ c: 43, r: 14 }],
    },
  ],

  crackHp: {
    "25,10": 5,
    "26,10": 5,
    "27,10": 5,
  },

  items: [
    { c: 22, r: 10, type: "shield" },
    { c: 10, r: 25, type: "drone" },
  ],

  fallingStones: [
    { c: 15, r: 8 },
    { c: 30, r: 12 },
  ],

  initialEnemies: 3,
};
```

---

## 十、注意事项

1. **地图边框**：最外圈必须是 BORDER(3)，否则坦克可能越界
2. **出生点安全**：玩家和敌人出生点周围不能有墙壁阻挡
3. **地图连通性**：确保所有出生点之间有可达路径
4. **格子值范围**：只能使用 0-7、9-12 的整数（8 已废弃）
5. **数组维度**：必须恰好 30 行，每行 45 列
6. **传送门放置**：传送门格子（GATE=2）会自动处理，无需手动在 map 中设置
7. **碎石墙 HP**：未在 crackHp 中指定的碎石墙默认 HP 为 2-3
8. **天空落石**：游戏过程中会自动从天空掉落落石（每5秒一块），可通过 `fallingStones` 配置落石位置，未配置时随机掉落
